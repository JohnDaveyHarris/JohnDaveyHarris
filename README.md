## Проекты

### 🌤 Weather Aggregator
Агрегатор прогнозов погоды из нескольких источников. Запрашивает данные
параллельно из **Open-Meteo**, **OpenWeatherMap** и **WeatherAPI**, нормализует
их к единой модели и показывает расхождения между источниками.

- **Стек:** React, TypeScript, RTK Query, Vite, shadcn/ui, Tailwind
- **Инженерия:** Vitest + RTL + MSW, CI через GitHub Actions, деплой на Vercel
- 🔗 ([Live demo](https://weather-aggregator-six.vercel.app/))

### 🎨 React UI Kit
Библиотека переиспользуемых компонентов с акцентом на доступность (a11y),
тёмную тему и полную инженерную обвязку.

- **Стек:** React, TypeScript, CSS Modules, Storybook, Playwright
- **Что внутри:** основные элементы формы: кнопки, поля ввода, селекты
- **Инженерия:** строгая типизация, e2e-тесты, a11y-проверки
- 🔗 ([Документация (Storybook)]( https://johndaveyharris.github.io/dt-ui-kit/))
